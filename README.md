# Wi-Fi Deauthentication Attack Simulator (Educational Use Only)

This tool allows users to simulate a Wi-Fi deauthentication attack using Scapy and a simple Tkinter GUI. This project is strictly for educational purposes and lab environments only.

## Features
- GUI interface for user-friendly control
- Deauthentication packet generator using Scapy
- Monitor mode toggler

## Usage
1. Ensure your wireless adapter supports monitor mode.
2. Run with `sudo`:
```bash
sudo python3 main.py
